# LLM Docs

This directory keeps only durable, high-signal docs for future agent sessions.

## Keep
- `DEVELOPMENT_SETUP.md` - local environment setup.
- `PRE_COMMIT_HOOK.md` - enforced commit checks and recovery flow.
- `MIGRATION_TO_BUN.md` - runtime/package-manager migration notes.
- `SHAREDDEPOSIT_SUBMODULE_INTEGRATION.md` - submodule integration details.
- `V2_ARCHITECTURE_EVOLUTION_CONTEXT.md` - GitBook-derived summary of v2 architecture and phased roadmap.

## Cleanup Policy
- Do not keep task handoffs, progress logs, one-off summaries, or generated reports here.
- Completed implementation notes should be removed once shipped.
- Historical detail remains in git history and PRs.
