# SharedStake V2

## Quick Start
```bash
# Deploy contracts
./scripts/deploy.sh contracts

# Deploy services
./scripts/deploy.sh services

# Backup database
./scripts/deploy.sh backup
```

## Environment
Copy `.env.production.example` to `.env.production` and fill in required values.
